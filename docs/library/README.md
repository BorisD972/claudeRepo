# Motion library

Une fiche par motion validé et réutilisable (`docs/library/<nom>.md`).

## Modèle de fiche

- **Nom** :
- **Description** : ce que fait le motion, en une ou deux phrases.
- **Fichier source** : `src/...`
- **Props** : nom, type, valeur par défaut, effet.
- **Contexte** : dans quel épisode il a été validé, pour quel usage, ce qu'il ne faut pas faire.
